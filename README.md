# 🏥 Аптека — Система учёта и продаж

Полноценная локальная система управления аптекой. Работает без интернета, все данные хранятся в SQLite.

## 📋 Возможности

- ✅ **Dashboard** — обзор продаж, прибыли, графики
- ✅ **Товары** — полный CRUD, поиск, фильтрация, импорт/экспорт Excel
- ✅ **POS Касса** — интерфейс продаж, штрихкоды, скидки
- ✅ **Склад** — приход, списание, возврат, история движения
- ✅ **Инвентаризация** — сверка остатков
- ✅ **Контроль сроков годности** — цветовая индикация 🟢🟡🔴
- ✅ **Поставщики** — карточки, история поставок
- ✅ **Отчёты** — продажи, выручка, прибыль, средний чек
- ✅ **Аналитика** — графики по дням, месяцам, категориям
- ✅ **Пользователи** — 4 роли с разграничением прав
- ✅ **Тёмная и светлая тема**
- ✅ **Экспорт** — XLSX, CSV, PDF

## 🔧 Требования

- **Node.js** 18.0 или выше
- **npm** 9.0 или выше
- **Windows / macOS / Linux**

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка базы данных

```bash
npm run setup
```

Эта команда автоматически:
- Создаст файл базы данных `database/apteka.db`
- Выполнит миграции Prisma
- Создаст администратора

### 3. Запуск проекта

```bash
npm run dev
```

Откройте браузер: **http://localhost:5173**

### Вход в систему

Выберите сотрудника на экране входа и введите PIN-код из 4 цифр. После первой установки:

| Сотрудник | PIN |
|-----------|-----|
| Администратор | 1234 |

Смените PIN в разделе «Админ → Настройки» сразу после первого входа. После 5 неверных попыток вход для сотрудника блокируется на 5 минут.

**Забыли PIN или обновились со старой версии** (где был пароль `admin123`): запустите `4_reset_admin_pin.bat` или выполните в папке `backend`:

```bash
npm run reset-pin -- admin 1234
```

PIN других сотрудников администратор меняет в разделе «Админ → Пользователи».

## 💾 Резервное копирование

В разделе «Админ → Настройки» нажмите «Скачать резервную копию»: скачается целостный снимок базы `apteka-backup-ГГГГ-ММ-ДД-ЧЧмм.db`. Его можно делать во время работы программы.

Для восстановления переименуйте копию в `apteka.db`, замените ею `database/apteka.db` и перезапустите приложение.

Файл `database/.jwt-secret` создаётся автоматически при первом запуске (ключ подписи сессий). Его не нужно копировать: если файл потерян, будет создан новый, и сотрудникам придётся войти заново.

## 📊 Импорт товаров

Поддерживаемые форматы: **XLSX**, **CSV**

Колонки файла (русские или английские названия):
- Наименование / name
- Производитель / manufacturer
- Страна / country
- Штрихкод / barcode
- Артикул / sku
- Закупочная цена / purchasePrice
- Цена продажи / sellingPrice
- Остаток / stock
- Мин. остаток / minStock

## ⚠️ Важно

- Все данные хранятся **локально** в файле SQLite
- Приложение работает **без интернета**
- Не используются облачные сервисы
- PIN-коды хранятся в хешированном виде (bcrypt), после 5 неверных попыток вход блокируется на 5 минут
- JWT токены действуют 24 часа; ключ подписи генерируется при первом запуске (`database/.jwt-secret`) или берётся из переменной `JWT_SECRET`
